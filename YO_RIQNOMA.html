Universitet elektron navbati

Yozuv: Ş, Ç, Ğ, Ö. Server, baza va barça sahifalar lokal işlaydi.

1. Birinçi işga tuşiriş

  1. ZIP’ni töliq oçing.
  2. Python 3.12 yoki yangiroğini örnating.
  3. BOSHLASH.cmd faylini ikki marta bosing.
  4. Yangi administrator parolini kiriting — kamida 12 belgi. Terilgan parol körinmaydi. Login: admin.
  5. Server oynasini yopmang. Kiosk oçiladi.

2. Asosiy jarayonni sinang

  1. Terminalda xizmat tanlang. Çipta çiqadi.
  2. Xodim paneliga admin bilan kiring va «Keyingisini çaqiriş»ni bosing.
  3. TV sahifasida çipta va oyna körinadi.
  4. Xodim sahifasida «Xizmatni boşlaş», keyin «Yakunlaş»ni bosing.

Bu sahifadagi manzillar sizning kompyuteringizdagi server uçun. Serverni işga tuşirgandan keyin oçiladi. Boşqa kompyuterda terminal IP manzilini işlating.

3. Ovozlarni keyin özingiz yuklaysiz

  1. sounds.rar arxivini kompyuteringizda oçing.
  2. Administrator → «Ovozlar» sahifasiga kiring.
  3. Çipta sözi, A harfi, 0–9 raqamlari va oyna sözini alohida WAV yoki MP3 fayllar bilan biriktiring. Har fayl 8 MB gaça.
  4. /tv-audio sahifasini oçing → «Yuklangan ovozlar» → «Ovozni yoqiş» → «Ovozni sinaş».

Yozuvlaringiz yuklanmagunça kompyuterdagi lokal ovozdan foydalaniş mumkin. Ovozlar internetdan olinmaydi.

4. Printer va avtomatik işga tuşiriş

Avval brauzer/PDF sinov rejimidan foydalaning. Haqiqiy printer uçun Windows drayverini örnating va Administrator → Sozlamalarda printer nomini kiriting.

Windows avtomatik xizmati uçun töliq tartib README.md içida. Xizmatni örnatişdan oldin oddiy rejimda sinang. Haqiqiy printer, TV ovozi va Windows qayta yoqilgandagi işlaş uşbu bulut muhitida tekşirilmagan.

5. Beş operator

Administrator → Xodimlar orqali beş alohida login va 1–5 oynani biriktiring. Har operator barça bölimlarni köradi va umumiy navbatdan, bölimdan yoki aniq çiptani çaqiradi. TVda har çaqiruv va qayta çaqiruv uç marta yonib-öçadi.

6. Hisobotni yuklab oliş

Administrator → Hisobotlar → sana oraliği → Körsatiş. Söng Excel, Word yoki PDFni bosing. Umumiy natijalar, bölimlar va operatorlar bir xil universitet şablonida beriladi. Vaqtlar soniyada.
